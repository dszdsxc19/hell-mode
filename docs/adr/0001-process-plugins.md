# ADR-0001：通过子进程扩展通知通道

采用显式 manifest 注册的可执行程序，以 `hell-mode/v1` JSON 协议提供 describe、notify 与 cancel。一次请求对应一个进程。

任务状态、验收和调度保留在 Go 核心。插件实现通知供应商差异，其他语言也可接入；配置、协议和环境变量规则独立于 Go 编译器 ABI。

[Go 原生 plugin](https://pkg.go.dev/plugin) 对平台、工具链和构建兼容有约束。子进程方式增加启动与序列化成本，但通知调用频率低，进程超时和输出隔离更容易验证。首版使用一次性请求，避免引入长期连接的重连与多路复用协议。

插件需本人显式信任，不自动扫描加载。进程分离不提供权限沙箱；插件拥有当前用户权限。stdout 只承载协议，日志与密钥通过独立通道处理。扩展点目前只覆盖通知，其他能力在真实用例出现后再定义协议。
