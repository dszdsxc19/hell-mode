# 地狱玩法脑暴

本文仅供娱乐，所有条目都是夸张玩梗与技术设想，项目定位见 [README](../README.md)。首版候选集中在失败检测、重复手机通知与明确接管；跨设备和物理世界玩法逐项验证。

这里保留早期创作设想。当前作品收束为「番茄失踪、本人回来、今天结束」，下列更多渠道、挑战和统计不进入本轮实现。

## 先抓住 Agent 的几种死法

| 玩法 | 具体场景 | 首版判断 |
| --- | --- | --- |
| 假下班稽查 | Agent 说「已完成」，独立验收发现测试没过或交付物缺失。 | 核心。按预先约定的证据验收。 |
| 尸检报告 | 进程异常退出，留下最后一条日志、退出码与失败步骤。 | 核心。通知要能直接用于处理。 |
| 装死雷达 | 该发心跳时没有心跳，连失败回调都没有。 | 核心。心跳说明存活，业务进展另行判断。 |
| 等你批准到天亮 | Agent 正在等权限、凭据或人工输入，工作实际上已停下。 | 有结构化等待事件时接入；不靠猜日志。 |
| 午夜预算熔断 | 执行触及本人设置的成本或时间上限，目标仍未完成。 | 后续接入有可靠账本的运行器。 |
| 原地转圈警报 | 连续重试同一失败、反复改回同一文件，几小时没有新证据。 | 实验。先提示疑似停滞，避免误判正常长任务。 |
| 清晨交付审计 | Agent 留下一篇漂亮总结，却没有约定的提交、产物或验证证据。 | 按目标契约检查；交付物由任务本人定义。 |

## 再让它越来越难忽略

| 玩法 | 地狱体验 | 实施位置 |
| --- | --- | --- |
| 夜班催命符 | 手机重复播放紧急通知，直到接管或到达本轮上限。 | 首版手机通道。 |
| 失败点名 | 语音读出任务名与一句失败原因：「支付回归还没过，你在睡什么？」 | 后续，本人设备与可选文案。 |
| 地狱来电 | 推送没人处理，拨打本人验证过的号码；按键进入接管入口。 | 后续，先验证地区、号码及供应商能力。 |
| 耳边值班长 | 通过本人配置的床头音箱播报，按预设间隔重复。 | 实验，需要设备联动。 |
| 房间变值班室 | 灯亮起，音箱播报，手机展示失败现场。 | 实验，使用稳定灯光及明确设备清单。 |
| 屏幕判决书 | 电脑回来后，待处理任务占据固定入口，显示「已等你 47 分钟」。 | 后续界面；保留正常关闭与解除布防操作。 |
| 未完成债务表 | 把同一晚多个失败合并成一份队列，按影响排序，避免各自轰炸。 | 多任务阶段。 |

## 防止「迷迷糊糊点掉」

| 玩法 | 如何确认本人真的开始处理 | 取舍 |
| --- | --- | --- |
| 清醒证明 | 展示失败摘要，选择「继续处理」「稍后处理」或「放弃」。 | 推荐默认交互；动作与责任直接相关。 |
| 五分钟赎命券 | 给一次短暂缓，到点仍未处理就恢复告警。 | 次数与间隔由本人布防时确定。 |
| 书桌签到 | 扫描电脑端本轮告警的短期二维码，直接打开失败现场。 | 实验；避免把手机通知当成任务入口的终点。 |
| 凌晨口试 | 选择当前失败的验收项，之后才完成普通接管。 | 可选娱乐模式；答案来自失败摘要。 |
| 复活任务 | 从固定入口重新执行验收或恢复任务，展示新旧结果。 | 后续；只运行事先配置的操作。 |
| 逃生按钮 | 无论开了什么模式，都可以立即解除布防。 | 基础能力；未完成目标继续留在记录里。 |

证明「足够清醒」无法靠一个按钮可靠完成。挑战交互只是减少误触，接管以本人明确操作为准。

## 地狱也要有剧情

- **温柔背叛**：第一条是「任务需要你帮一下」，第三档变成「它已经放弃了，现在轮到你」。
- **午夜 Boss 战**：失败的验收项是一排血条；每次修复并重新验收，消掉一条。
- **天亮追债**：早上只给自己列出昨夜未达成目标、叫人次数、暂缓次数和实际处理时间。
- **失败遗言**：通知优先展示 Agent 最后执行的动作与阻塞证据；幽默文案单独标成文案，不冒充事实。
- **地狱账单**：把投入时间、可靠计量的调用成本与处理耗时放在同一记录里。缺少账本时显示未知。
- **清白之夜**：只有经过验收的目标才在早晨进入「昨晚完成」列表。

## 三档预设草案

下表表示完整愿景。具体间隔、设备和预算在布防前展示；电话与设备联动尚未实现。

| 预设 | 适合的任务 | 叫人方式 |
| --- | --- | --- |
| `ember` · 余烬 | 白天或低影响任务 | 普通提醒与待处理记录。 |
| `hell` · 地狱 | 今晚必须关注结果的任务 | 桌面声音、重复手机紧急通知、到期暂缓。 |
| `inferno` · 炼狱 | 本人明确要求夜间叫醒 | 推送后升级本人电话，可选灯与音箱，按预设上限运行。 |

模式名称决定语气和建议配置，实际执行以本次确认的策略为准。

## 选题判断

最先做「假下班稽查 + 装死雷达 + 夜班催命符 + 清醒证明」。它们能覆盖一个真实夜间任务从失败到本人接手的过程。

电话和房间联动能制造强烈的地狱体验，价值取决于真实设备触达率和误报率，排在核心链路验证之后。社交曝光、通知同事、自动花钱惩罚、锁住设备以及控制有危险的电器不在项目方向内。
